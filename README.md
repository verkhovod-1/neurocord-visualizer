# NeuroCord Visualizer

Устанавливаемый PWA-визуализатор для Android и настольных браузеров. Чистый HTML/CSS/JS, без платной подписки и водяных знаков.

## Возможности
- Загрузка аудио и обложки
- Три визуальных стиля: Neon Spectrum, Waveform, Neural Space
- Изменение названия, исполнителя, цветовой палитры и размера визуализатора
- Запись видео 1920×1080, 30 fps, с аудиодорожкой
- Финальная заставка NeuroCord
- PWA manifest, service worker, иконка
- Если браузер пишет WebM, можно попробовать конвертацию в MP4 через FFmpeg.wasm из бесплатного CDN

## Запуск и установка на Android
PWA требует HTTPS (или localhost). Самый простой вариант — GitHub Pages:
1. Создайте публичный репозиторий GitHub, например `neurocord-visualizer`.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте **Settings → Pages**, выберите ветку `main` и папку `/ (root)`, сохраните.
4. После публикации откройте адрес Pages в Chrome на Android.
5. В меню Chrome `⋮` выберите **Установить приложение** или **Добавить на главный экран**.

## Как использовать
1. Загрузите аудио.
2. Добавьте обложку, название трека и исполнителя.
3. Выберите стиль и цвет.
4. Нажмите «Создать видео». Запись выполняется в реальном времени, поэтому песня длительностью 4 минуты записывается примерно 4 минуты.
5. Не закрывайте вкладку, не блокируйте экран и не переключайтесь в другое приложение во время экспорта.
6. Скачайте результат. Если получился WebM, используйте «Конвертировать в MP4». Для конвертации требуется интернет, поскольку FFmpeg.wasm загружается с CDN.

## Ограничения браузеров
- Приложение не гарантирует нативный MP4: формат зависит от MediaRecorder и кодеков браузера/устройства. На многих Android-устройствах нативная запись будет WebM.
- Конвертация FFmpeg.wasm в MP4 ресурсоёмкая; на слабых телефонах может не хватить памяти. Тогда скачайте WebM и конвертируйте его на компьютере.
- Экспорт идёт в реальном времени. Для стабильного результата держите экран включённым.
- Файлы песни и обложки обрабатываются локально в браузере; приложение не загружает их на сервер.
- При первом запуске конвертера требуется интернет. Основной визуализатор может работать после установки PWA в офлайн-режиме.

## Структура
- `index.html` — интерфейс
- `style.css` — оформление
- `app.js` — визуализация и экспорт
- `manifest.webmanifest` — PWA manifest
- `sw.js` — кэширование
- `icon.svg` — иконка
