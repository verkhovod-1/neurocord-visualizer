# NeuroCord Visualizer v7.4 — Subject Motion Fix

v7.4 исправляет слишком слабую анимацию среднего слоя (главного объекта). В v7.3 смещение и изменение масштаба главного объекта были заметно слабее переднего плана. Теперь у главного объекта отдельные плавные колебания по X/Y, дополнительный отклик на бас и более заметное изменение масштаба. Передний план сохраняет ведущую глубину и остаётся более подвижным.

Параллакс по-прежнему управляется переключателями «Живое движение обложки» и «Включить 3D-параллакс», общей силой движения и индивидуальными ползунками глубины. Раздвижение слоёв для проверки сохранено.

Проверки этой сборки: синтаксис JavaScript и целостность ZIP. Реальная проверка на Android не выполнялась.


v7.3 исправляет геометрию композитинга: фон и прозрачные PNG-слои теперь используют единое кадрирование для горизонтального и вертикального видео. Добавлена панель проверки видимости каждого слоя. Сохраняются Smart Cover Director, Cinema FX PRO, BAR LAB PRO, AI Director и экспорт.

## Что нового
- **Cinema FX PRO:** семь независимых эффектов — световые лучи, космическая пыль, энергокольца, неоновый дождь, голографический скан, энергетические осколки и световые волны.
- Для каждого эффекта есть собственная сила 25–150%. Общая сила эффектов также регулируется отдельно и работает как мастер-множитель.
- Эффекты реагируют на низкие, средние и высокие частоты музыки; интенсивность, плотность и амплитуда адаптируются к звуку.
- **Living Cover:** мягкий параллакс, плавное приближение и движущийся свет поверх полноэкранной обложки. Анимацию можно отключить.
- Удалён квадратный формат. Доступны только 16:9 (1920×1080) и 9:16 (1080×1920).
- Сохранены базовые стили, BAR LAB PRO, AI Director, загрузка аудио/обложки и экспорт.

## Новое в v7.0 — разделение обложки на слои
1. Загрузи обложку JPG/PNG.
2. Открой «Разделить текущую обложку на 3D-слои».
3. Выбери «Главный объект» и закрась кистью предмет/персонажа.
4. Выбери «Передний план» и отдельно закрась элементы, которые должны двигаться ближе (например, надпись или ступени).
5. Используй ластик и очистку маски, если нужно поправить выделение.
6. Нажми «Создать 3D-слои». Программа локально соберёт фон с мягким заполнением выделенных областей и два прозрачных слоя. Они сразу подключатся к предпросмотру и экспорту.
7. Включи «Живое движение обложки» и настрой силу 3D-параллакса.

**Важно:** сегментация v7.0 — ручная кистевая разметка с автоматической сборкой слоёв, а не нейросетевое распознавание объектов. Для аккуратного края тщательно прокрашивай контур и используй ластик. Фон под удалёнными объектами восстанавливается мягким размытием исходной обложки; сложный фон может потребовать ручной доработки.

## Использование
1. Загрузи аудио и обложку.
2. Выбери базовый визуальный стиль.
3. Включи нужные Cinema FX и настрой силу каждого. Общая сила задаёт общий уровень всех включённых эффектов.
4. При желании оставь включённым «Живое движение обложки».
5. Выбери 16:9 для обычного YouTube или 9:16 для Shorts.
6. Нажми «Создать видео» и дождись окончания записи, не закрывая приложение и не блокируя экран.

## Производительность и ограничения
- Эффекты нарисованы на Canvas без тяжёлого 3D-движка и CSS-фильтров.
- На телефонах количество частиц и сложность отрисовки ограничиваются облегчённым режимом.
- Экспорт выполняется в реальном времени. На телефонах целевая частота — до 24 кадров/с.
- В зависимости от браузера файл может быть сохранён в WebM; доступна попытка конвертации в MP4 через FFmpeg.wasm.
- Аудио и обложка обрабатываются локально в браузере.

## Установка через GitHub Pages
Загрузи содержимое этой папки в корень репозитория, сохранив структуру файлов. Открой GitHub Pages в Chrome на Android. Если приложение показывает старую версию, полностью закрой его и открой заново; при необходимости очисти данные сайта в Chrome.

## v7.3 — 3D Depth Studio
- Added independent depth controls for background, subject and foreground planes.
- Added parallax enable/disable, global movement strength, and temporary layer spread for alignment inspection.
- Added one-click depth reset. At spread 0%, layers retain their registered base alignment.
- Updated service-worker cache key to force the new PWA assets to load.
- Parallax is a lightweight 2D canvas simulation; it does not create real 3D geometry.
